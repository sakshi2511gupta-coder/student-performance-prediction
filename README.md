# 🎓 Student Performance Prediction Website

A simple and responsive web application that predicts student academic performance based on study hours, attendance, previous marks, and assignment score.

# 🌐 Live Demo 
https://sakshi2511gupta-coder.github.io/student-performance-prediction/

## 📌 Project Description

The Student Performance Prediction Website is a beginner-friendly project developed using HTML, CSS, and JavaScript.

Users can enter a student's academic information, and the website calculates an estimated performance score and displays the performance category.

## ✨ Features

* 📚 Study hours input
* 📅 Attendance percentage input
* 📊 Previous marks input
* 📝 Assignment score input
* 🎯 Performance prediction
* 📈 Performance analysis chart
* 📱 Mobile responsive design
* 🎨 Clean and modern user interface

## 🛠️ Technologies Used

## 🧮 Prediction Method

The estimated performance score is calculated using the following weights:

* Study Hours: 20%
* Attendance: 25%
* Previous Marks: 30%
* Assignment Score: 25%

## 📊 Performance Categories

| Score      | Performance          |
| ---------- | -------------------- |
| 85% – 100% | Excellent 🌟         |
| 70% – 84%  | Good 👍              |
| 50% – 69%  | Average 📚           |
| Below 50%  | Needs Improvement ⚠️ |

## 🚀 How to Use

1. Open the Student Performance Prediction website.
2. Enter study hours per day.
3. Enter attendance percentage.
4. Enter previous marks.
5. Enter assignment score.
6. Click **Predict Performance**.
7. View the predicted score and performance category.
